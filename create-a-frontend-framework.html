Templating

Template are one of the core elements of frontend frameworks.

They permit to inject data, to reuse components, to build interfaces faster while injecting the data.

Every frontend frameworks has their template engine, but the book I read used the simple example of the interpolation operator in js.

Interpolation permits to contatenate more easily strings. In js they permits to add data's value directly into string, to manipulate strings into a certain manner using tagged interpolation.

The latter is the system upon we base our implementation.

Something like that : 

const createElement = tagName => (strings, ...args) => ({
  type: tagName,
  template: strings.reduce((acc, currentString, index) => `${acc}${currentString}${args[index] || ''}`, "")
});

export const div = createElement("div");
export const p = createElement("p");

With the type and content here, we can just do a check and inject the element into the DOM : 

export const User = ({ firstName, lastName }) => div`Hello ${firstName} ${lastName}`;

import { div } from "./framework/element";
import { User } from "./src/user";

const firstName = "Anne-Marie";
const lastName = "Koffi";

init("#app", User({ firstName, lastName }));

Here it's we have a component into our template system which is called div, which will return "Hello Sam Van"
